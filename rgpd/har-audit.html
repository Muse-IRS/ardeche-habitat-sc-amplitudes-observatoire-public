Le fichier reste dans votre navigateur. L’outil extrait uniquement les éléments nécessaires à un audit technique borné et permet d’exporter un rapport minimisé.

Principe

Un HAR peut contenir des URL, cookies, identifiants, paramètres ou données de session. Cet outil n’envoie pas le fichier au serveur de l’observatoire. L’analyse JavaScript s’effectue dans le navigateur qui ouvre cette page.

FICHIER HAR LOCAL→ANALYSE DANS LE NAVIGATEUR→RAPPORT MINIMISÉ

Ce que l’outil ne remplace pas

Un HAR ne contient pas nécessairement le contenu du stockage local du navigateur (localStorage et sessionStorage), ni le comportement clavier, le focus, le zoom ou les annonces d’un lecteur d’écran. Ces observations restent séparées.

Important : le stockage navigateur est un complément facultatif. Si vous ne savez pas le relever, laissez les champs vides plutôt que de copier une donnée sensible.

Stockage du navigateur — facultatif

Vous pouvez analyser le HAR sans remplir les deux champs suivants. Ils servent seulement à compléter l'observation si vous avez regardé ce que le site conserve localement dans votre navigateur.

Nous attendons uniquement les noms des clés, par exemple cookie_consent, theme ou analytics_state. Ne copiez jamais la colonne des valeurs, un jeton, un identifiant de session, une adresse e-mail ou du JSON complet.

Une clé par ligne. Si vous ne savez pas où les trouver, laissez ce champ vide : l'analyse HAR fonctionnera quand même.

Même règle : noms seulement, jamais les valeurs.

Comment trouver ces noms dans mon navigateur ?

Ouvrez d'abord le site que vous auditez, puis utilisez les outils du navigateur. Vous cherchez uniquement la colonne qui contient les noms des clés.

  • Chrome / Edge / Chromium sur ordinateur : ouvrez les outils de développement → Application → Storage → Local Storage ou Session Storage → choisissez le domaine du site. Recopiez seulement les noms de la colonne Key.
  • Firefox sur ordinateur : ouvrez les outils de développement → Stockage → Stockage local ou Stockage de session → choisissez le domaine. Recopiez seulement les noms.
  • Safari sur Mac : ouvrez l'inspecteur Web depuis le menu de développement, puis la zone de stockage. Recopiez uniquement les noms de clés.
  • iPhone / iPad : il n'existe pas de chemin simple équivalent directement dans Safari mobile. Vous pouvez laisser ces champs vides. Ils ne sont pas obligatoires.

À ne pas coller : la valeur d'un cookie, un contenu ressemblant à eyJ..., une longue chaîne aléatoire, un e-mail, un identifiant personnel, un objet JSON ou toute donnée que vous ne comprenez pas.

2. Ce qui est extrait

  • statuts HTTP et redirections ;
  • security response headers sélectionnés ;
  • signaux TLS présents dans le HAR ;
  • cookies sous forme de métadonnées, jamais leurs valeurs ;
  • domaines tiers et requêtes HTTP non chiffrées observées ;
  • signaux analytics, captcha et paiement par heuristique.

Exclus de l’export : valeurs de cookies, Authorization, corps POST, corps des réponses, query strings, fragments d’URL, nom local du HAR et nonces CSP.
