Confidentialité

Le moins de données possible.

Cette notice décrit le comportement actuel de l’observatoire public. Elle ne remplace pas les politiques propres à GitHub, ADEME ou aux autres services ouverts volontairement par le visiteur.

Ce que l’observatoire ne fait pas actuellement

  • aucun compte utilisateur ni profil visiteur ;
  • aucun formulaire de collecte transmis à un serveur de l’observatoire ;
  • aucune publicité ni SDK publicitaire ;
  • aucun stockage local applicatif dans le code audité ;
  • aucun cookie applicatif écrit par le code audité ;
  • aucun chargement GTM/GA4 dans l’état public actuel ;
  • aucune conservation serveur par l’observatoire des numéros DPE recherchés.

Hébergement

GitHub Pages sert les fichiers statiques. L’hébergeur peut traiter les données techniques nécessaires à la connexion, notamment l’adresse IP et des informations de requête, selon ses propres conditions. Ces journaux ne sont pas contenus dans ce dépôt.

Recherche DPE

Lorsque vous saisissez un numéro puis lancez la recherche, votre navigateur interroge directement les jeux publics ADEME. L’observatoire n’ajoute pas de serveur intermédiaire. L’adresse précise et les coordonnées restent masquées dans la vue détaillée ; l’adresse complète n’est révélée que sur action explicite lorsqu’elle existe dans la source.

Analyse HAR locale

La page RGPD « Analyse HAR locale » peut lire un fichier HAR choisi par le visiteur. Le fichier est traité localement par JavaScript dans le navigateur : il n’est pas téléversé vers GitHub ni vers un serveur de l’observatoire, et le code n’utilise ni cookie applicatif ni stockage Web pour le conserver. L’export du rapport minimisé est déclenché uniquement par l’utilisateur et exclut les valeurs de cookies, les corps POST, les en-têtes d’autorisation et les paramètres de requête bruts.

Liens externes

Les sources officielles et techniques sont proposées sous forme de liens. La connexion au service tiers intervient lorsque vous choisissez d’ouvrir ce lien. Le site utilise une politique de référent no-referrer afin de limiter la transmission de l’URL de provenance par le navigateur.

Droits et correction des informations publiées

Certaines pages peuvent citer des personnes dans un contexte strictement professionnel à partir de sources publiques. Une erreur factuelle doit pouvoir être corrigée. Le canal privé d’exercice des droits de l’éditeur reste à formaliser ; en attendant, ne transmettez jamais de pièce d’identité ni d’information personnelle dans une issue GitHub publique.

Pour comprendre les droits d’accès, de rectification, d’effacement, de limitation, d’opposition ou de portabilité selon les situations, consultez la page RGPD de l’observatoire et les ressources officielles de la CNIL qui y sont référencées.

État daté

Notice correspondant à l’audit public mis à jour le 20 septembre 2026. Toute évolution des services utilisés doit produire un nouvel état documenté.
